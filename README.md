# 🧳⚡ VibeTrip — Anti-Design Trip Planner

VibeTrip is a dynamic, neo-brutalist web application designed for travelers who want curated 1-day city timelines without dealing with complex travel forms, bloated APIs, or algorithmic clutter.

🚀 **Live Web Application:** [https://vibe-trip-planner-five.vercel.app/](https://vibe-trip-planner-five.vercel.app/)

---

## ✨ Features

- 🎨 **Dynamic Theme Shifting:** Color palettes, borders, alert banners, and typography dynamically adapt to the selected vibe (*Cyberpunk*, *Cozy*, *Underground Art*, or *Chaos*).
- 🎲 **Chaos Mode:** Randomizes city/vibe pairings accompanied by custom CSS screen-shake animations.
- 🔀 **Option A / Option B Cards:** Interactive activity cards that allow users to customize their route in real-time.
- 📍 **Instant Navigation:** Direct integration with Google Maps search queries for every location on the timeline.
- 🖨️ **"Ditch Your Phone" Offline Challenge:** Generates a printable thermal receipt with route checklists, duration/cost estimates, and city survival language phrases for offline exploration.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document structure
- **Tailwind CSS:** Responsive styling, custom Neo-Brutalist utility classes, and custom keyframe animations
- **Vanilla JavaScript (ES6+):** Client-side state management, theme engine, print template rendering, and DOM manipulation
